# Linux for eLife boxes

Linux on Etisalat eLife boxes.

A small project for getting a proper Linux system running on these boxes and figuring out whatever the fuck Etisalat put inside them.
this is very much a work in progress. it uses alpine too

## Build

```sh
mkdir build
cd build
cmake ..
cmake --build .
```

## Run

you know how to use adb right?

## Warning

Don't mess with the bootloader unless you know what you're doing.

You can brick the box. Seriously.
